Observation Terms¶

Built-in observation terms, compiled from source. Framework-level terms are re-exported at unilab.envs.mdp.<name>.

Authoritative signatures live in the source tree: unilab/envs/mdp, unilab/tasks.

Framework (unilab.envs.mdp.observations)¶

Source: src/unilab/envs/mdp/observations.py. Terms that read the physics state go through the Manager packed Torch read plan; sensor terms bind one existing named backend sensor at construction and fail closed when the backend cannot provide it.

Ray scans (unilab.envs.mdp.ray_observation)¶

Source: src/unilab/envs/mdp/ray_observation.py. RayScan binds a UniSim tensor ray caster (factory name in RayPatternCfg.caster, default "uni_ray") attached to a scene body or site, traces the declared pattern every step, and returns per-ray distances; include_normal / include_hit_point append 3 values per ray each, flattened. Caster capabilities are checked at read-phase binding and unsupported features fail closed. No shipped owner YAML references RayScan yet; coverage lives in tests/envs/mdp/test_ray_observation.py.

Per-ray distances from the configured pattern (ray_count values, plus normals / hit points when enabled).

Unit ray directions for a pinhole camera in an explicit local frame.

Locomotion — shared terms¶

quadruped_gait_phase is defined in src/unilab/tasks/locomotion/common/manager_terms.py; the four privileged per-foot terms are defined in src/unilab/tasks/locomotion/common/gait_terms.py and mirror the mjlab velocity-task critic observations.

Term

Function / class

Parameters

Semantics

quadruped_gait_phase

unilab.tasks.locomotion.common.manager_terms.quadruped_gait_phase (class)

frequency: float = 2.0 (Hz); phase_offsets: list[float] = (0.0, 0.5, 0.5, 0.0); command_name: str | None = None; command_threshold: float = 0.0

Four-foot phase observation in [0, 1) with the diagonal-trot ordering; advances only while the command norm exceeds command_threshold when command_name is set.

World-frame foot body z, shape (num_envs, num_feet); exact on flat terrain.

Current per-foot air time in seconds, shape (num_envs, num_feet).

foot_contact

unilab.tasks.locomotion.common.gait_terms.foot_contact (class)

sensor_groups: list[list[str]] (required); contact_threshold: float = 0.0

Per-foot contact flag as float, shape (num_envs, num_feet).

foot_contact_forces

Log-compressed per-foot contact forces sign(f) * log1p(|f|), shape (num_envs, 3 * num_feet).
