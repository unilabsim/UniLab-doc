UniLab Documentation¶

UniLab

Contract-driven robot learning infrastructure for MuJoCo and Motrix.

UniLab keeps task ownership in Hydra config, isolates backend-specific behavior behind SimBackend, and routes training through explicit scripts. Start with a known task, then move to backend selection, algorithms, transfer, or extension work as needed.

Developer Guide

Quick install¶

curl -LsSf https://astral.sh/uv/install.sh | sh
git clone https://github.com/unilabsim/UniLab.git
cd UniLab
uv sync --extra motrix
uv run scripts/train_rsl_rl.py task=go2_joystick_flat/motrix

For platform-specific dependency paths, see Installation.
